# Книжкова бібліотека
Книжкова бібліотека - застосунок для зберігання та обліку книг. Для збереження інформації використовується база даних SQLite.

## Функціонал
Застосунок має такі можливості:
- Додавання нових книг із зазначенням назви, автора, кількості сторінок та жанру.
- Перегляд списку всіх доданих книг.
- Позначення книг як прочитаних або непрочитаних.
- Видалення книг із бібліотеки.
- Пошук книг за автором.
- Фільтрація за статусом прочитання.
- Сортування книг за датою додавання.
- Відображення статистики: загальна кількість книг та кількість прочитаних.

## Інструкція з запуску

Для запуску проєкту необхідно мати встановлений Flutter SDK та Visual Studio з компонентами для розробки Windows-застосунків.

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту у VS Code.
3. Відкрити термінал у папці проєкту.
4. Виконати команду для встановлення залежностей:
flutter pub get

5. Перевірити доступні пристрої:
flutter devices


6. Запустити застосунок на Windows:
flutter run -d windows

## Структура проєкту

```text
lib/
├── database/
│   └── database_helper.dart
├── models/
│   └── book.dart
├── repositories/
│   └── book_repository.dart
├── screens/
│   ├── home_screen.dart
│   └── add_book_screen.dart
└── main.dart
```

Також у корені проєкту знаходяться:

- windows/ - файли для запуску застосунку на Windows.
- `pubspec.yaml` - інформація про проєкт та його залежності.
- `pubspec.lock` - зафіксовані версії пакетів.
- `.metadata` - службова інформація Flutter.

## Опис коду
main.dart
Головний файл програми. Відповідає за запуск застосунку, налаштування зовнішнього вигляду та ініціалізацію SQLite для Windows.

models/book.dart
Містить клас Book, який описує книгу та її основні властивості: назву, автора, кількість сторінок, жанр, статус прочитання і дату додавання.

database/database_helper.dart
Відповідає за створення та налаштування бази даних SQLite, таблиці для зберігання книг та індексу за автором.

repositories/book_repository.dart
Містить основні операції з книгами: додавання, отримання, пошук, фільтрацію, зміну статусу прочитання та видалення.

screens/home_screen.dart
Головний екран застосунку. На ньому відображається список книг, статистика, пошук, фільтрація та сортування.

screens/add_book_screen.dart
Містить форму для введення інформації та додавання нової книги до бібліотеки.
